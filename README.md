# SWIPEASIA

Telegram мини-апп от команды «Азия без стресса»: анкета поездки → свайп мест → маршрут по дням на карте. Первый город - Нячанг.

Этап 2 ТЗ: прототип без оплаты. Одна страница на HTML/CSS/JS без сборки, хостинг Vercel.

- `data/nhatrang.js` - места (генерируется из таблицы мест, руками не править)
- `js/route.js` - сборка маршрута по правилам (без ИИ)
- `js/app.js` - экраны
- `data/photos.js` - список id мест, у которых есть своё фото в `img/places/<id>.webp`
- `img/cat` - фото категорий («фото для настроения»), `img/ui` - анкета и обложка
- `vendor/leaflet` - карта, тайлы OpenStreetMap

Цены Grab приблизительные: замеры от ЖК Panorama, в городе ≈ 6 200 ₫ за км по прямой (мин. 13 000 ₫).

Maxim считаем как Grab × 0,75 (по опыту Миши на 20-30% дешевле), цена приблизительная.

Геопозиция: Telegram LocationManager (Bot API 8.0+), запасной вариант - геолокация браузера. Точку дальше 40 км от Нячанга не берём.

Рулетка «Живу в Нячанге»: что хочется, бюджет, настроение (по словам в описании места), рядом или по всему городу → случайное место, свайп влево крутит ещё раз.
